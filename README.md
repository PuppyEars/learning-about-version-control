# Learning About Version Control
## Author: Quinn Scheider

Solving merge conflicts takes conscious effort, but I can do it!

One thing I like about version control is you have to have someone else review your code before you add it to the main branch. It makes you to have make sure what you push won't break the original branch.

I think the most challenging part is when you push things and you forget to check what branch you're on. I've made that mistake already and fixing it takes a little bit of grevience to do.
